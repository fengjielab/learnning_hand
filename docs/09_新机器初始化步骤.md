# 新机器初始化步骤

这份文档回答一个最常见的问题:

“我在新 Linux 电脑上 `git clone` 下来以后，接下来到底怎么做？”

最重要的结论先说:

- GitHub 里主要保存代码、脚本、文档和依赖说明
- GitHub 一般不会保存你本地现成的虚拟环境
- 所以到了新电脑上，通常要重新创建虚拟环境，再安装依赖

---

## 1. 拉取代码

```bash
git clone <你的仓库地址>
cd teletest_forcedimension
```

如果你已经把远端配置成 SSH，也可以直接用 SSH 地址 clone。

---

## 2. 先创建虚拟环境

```bash
python3 -m venv handvenv
```

这一步是在新电脑上重新创建一个干净的 Python 虚拟环境。

注意:

- `handvenv/` 这个目录通常不会跟着 GitHub 一起下来
- 所以不要期待 clone 完就能直接 `source`

---

## 3. 进入虚拟环境

```bash
source handvenv/bin/activate
```

这一步只是“进入虚拟环境”，不是“安装依赖”。

---

## 4. 安装 Python 依赖

现在这个项目已经补了仓库级依赖文件:

- [requirements.txt](/home/mfj/teletest_forcedimension/requirements.txt)

所以你在新机器上可以直接执行:

```bash
pip install -r requirements.txt
```

这里面包括了:

- `forcedimension-core`
- `numpy`
- `mujoco`
- `scipy`

---

## 5. 再处理系统依赖和设备环境

Python 依赖装完，还不代表 Omega.7 就能工作。

你还要继续处理:

- `libusb`
- `udev` 规则
- Force Dimension SDK (`libdhd`, `libdrd`)

最推荐直接执行:

```bash
sudo bash scripts/02_setup_omega7_environment.sh
```

这个脚本现在会优先读取 `requirements.txt` 安装 Python 依赖。

---

## 6. 最后做最小测试

先跑最简单的宿主机测试:

```bash
source handvenv/bin/activate
python3 tests/01_basic_device_connection.py
```

如果这一步通了，再继续更复杂的调试、力反馈、Mujoco 测试。

---

## 7. 一个完整的常见流程

```bash
git clone <你的仓库地址>
cd teletest_forcedimension
python3 -m venv handvenv
source handvenv/bin/activate
pip install -r requirements.txt
sudo bash scripts/02_setup_omega7_environment.sh
python3 tests/01_basic_device_connection.py
```

---

## 8. 你现在最该记住的一句话

未来换到新 Linux 电脑上时，不是:

- clone 下来
- 直接 `source`

而是:

- clone 下来
- 新建虚拟环境
- `source`
- `pip install -r requirements.txt`
- 再跑环境配置脚本和测试
